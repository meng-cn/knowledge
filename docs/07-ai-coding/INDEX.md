# AI Coding 全景知识体系

## 🗺️ 从代码补全到 Agentic Coding 的技术演进

本知识库系统整理 AI 编程的完整知识体系，重点对比 Vibe Coding 与 Spec-Driven Development 两种编程范式。

### 📖 核心内容

- **基础概念** — AI 结对编程、AI-Optimized PRD
- **Vibe Coding** — Karpathy 命名的对话式编程范式
- **Spec Coding** — PRD 驱动的开发范式
- **Vibe vs Spec 对比** — 系统性对比与选型指南
- **工具生态** — Cursor / Copilot / Claude Code / Cody 等
- **工程实践** — PRD 模板 + 提示工程 + 质量保障
- **前沿趋势** — Agentic Coding + 多模态 + 企业落地

### 🎯 核心结论

| 问题 | 答案 |
|--|-|
| **Vibe Coding vs Spec Coding 谁更好？** | 没有绝对好坏，取决于场景 |
| **什么时候用 Vibe？** | 创意探索、快速原型、个人项目 |
| **什么时候用 Spec？** | 生产代码、团队协作、复杂系统 |
| **最好的策略？** | **Vibe 探索 + Spec 落地** 混合模式 |
