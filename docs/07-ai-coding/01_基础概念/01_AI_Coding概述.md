# AI Coding 概述

> **在知识图谱中的位置**：模块一 · 01_基础概念 · 第 1 节

---

## 1. 概述

**AI Coding** 是指利用大语言模型（LLM）辅助软件开发的全过程。从代码补全到完整的 Agent 驱动开发，AI Coding 正在重新定义软件开发方式。

---

## 2. 技术演进

| 阶段 | 时间 | 特征 | 代表 |
|--|-|--|-|
| 代码补全 | 2015-2018 | 基于历史代码的模式匹配补全 | Kite, TabNine |
| Copilot | 2019-2021 | GitHub Copilot (OpenAI Codex) | GitHub + OpenAI |
| LLM 助手 | 2022-2024 | ChatGPT-4 / Claude 驱动的编程 | ChatGPT, Claude |
| AI IDE | 2025+ | 原生 AI 的 IDE | Cursor, Windsurf, Claude Code |
| Agent 编程 | 2026+ | Agent 自主执行开发任务 | OpenAI Codex, Devin |

---

## 3. AI Coding 的核心能力

### 3.1 代码生成

- 从自然语言描述生成代码
- 上下文感知的代码补全
- 整文件/整函数生成

### 3.2 代码理解

- 解释代码库架构
- 代码审查与改进建议
- Bug 检测与修复

### 3.3 代码转换

- 语言迁移（如 JavaScript → TypeScript）
- 框架迁移（如 React → Vue）
- 代码重构

### 3.4 代码测试

- 自动生成测试用例
- 测试驱动开发辅助
- 覆盖率分析

---

## 4. AI Coding 的范式演进

### 从补全到 Agent

```
代码补全 → 对话式编程 → Agent 自主开发
  (Copilot)  (Vibe Coding)  (Agentic Coding)
```
