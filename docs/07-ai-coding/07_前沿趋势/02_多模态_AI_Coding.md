## 1. 多模态 AI Coding 概述

多模态 AI Coding 是指 AI 编程助手不仅能处理代码和文本，还能理解图像、音频、视频等多模态输入。

### 应用场景

| 模态 | 场景 |
|--|-|
| **图像** | 从 UI 设计图生成代码 |
| **音频** | 语音指令生成代码 |
| **视频** | 从屏幕录制提取交互逻辑 |
| **3D** | 从 3D 模型生成交互代码 |
