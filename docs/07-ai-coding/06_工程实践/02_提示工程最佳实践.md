## 1. AI 编程提示工程核心原则

### 原则一：提供上下文

给 AI 足够的代码上下文：

```
❌ "修复这个 Bug"
✅ "在 src/api/auth/login.ts 第 25 行，当密码验证失败时，返回 401 而不是 500。
    当前代码：...（粘贴代码）"
```

### 原则二：明确约束

指定技术栈、框架、编码规范：

```
"用 React + TypeScript 重写这个组件。
遵循 Airbnb JavaScript Style Guide。
使用 functional components + hooks。"
```

### 原则三：分步请求

大任务拆成小步骤：

```
Step 1: "Create a basic todo list component"
Step 2: "Add edit functionality with a modal dialog"
Step 3: "Add filtering by status"
```

### 原则四：指定输出格式

```
"以 JSON 格式返回 API 设计
以 SQL 格式返回数据库 Schema
以 Markdown 格式返回 PRD"
```

## 2. 常用 Prompt 模板

### 代码生成 Prompt

```
你是一位 senior [语言] 开发者。请根据以下 PRD 生成完整代码：

# PRD
[粘贴 PRD]

要求：
1. 使用 [技术栈]
2. 遵循 [编码规范]
3. 包含错误处理
4. 添加 JSDoc/文档字符串
```

### 代码审查 Prompt

```
请审查以下代码，重点关注：
1. 安全漏洞
2. 性能问题
3. 代码风格
4. 边界情况

代码：
[粘贴代码]

请用 Markdown 格式输出审查结果。
```

### Bug 修复 Prompt

```
以下代码在 [场景] 时会崩溃：

代码：
[粘贴代码]

错误信息：
[粘贴错误信息]

请：
1. 分析 Bug 原因
2. 提供修复代码
3. 解释修复原理
```
