## 1. AI 生成代码的审查策略

### 1.1 必须人工审查的地方

| 代码类型 | 审查强度 |
|--|-|
| 安全相关代码 | 🔴 必须人工审查 |
| 核心业务逻辑 | 🔴 必须人工审查 |
| API 端点 | 🟡 重点审查 |
| 数据库 Schema | 🟡 重点审查 |
| UI 组件 | 🟡 重点审查 |
| 工具函数 | ⚪ 可自动化审查 |
| 测试用例 | 🟡 重点审查 |

### 1.2 AI 代码审查 Checklist

- [ ] 功能是否满足需求
- [ ] 是否有安全漏洞
- [ ] 是否有性能问题
- [ ] 代码风格是否一致
- [ ] 边界情况是否处理
- [ ] 错误处理是否完整
- [ ] 是否有重复代码
- [ ] 变量命名是否清晰
- [ ] 注释是否充分

---

## 2. AI 辅助 Code Review 流程

```
Step 1: AI 自动审查代码（自动化 Checklist）
Step 2: AI 输出审查报告
Step 3: 人工审查 AI 审查报告
Step 4: 人工补充审查
Step 5: 合并
```
