# Cody 及其他工具对比

> **在知识图谱中的位置**：模块五 · 05_工具生态 · 第 5 节
> **难度**：⭐⭐

---

## 1. Sourcegraph Cody

**Sourcegraph Cody** 是基于 Sourcegraph 代码库理解的 AI 编程助手。其核心优势是索引整个代码库（包括私有仓库），提供跨仓库的代码理解和生成。

### 核心特性

| 特性 | 说明 |
|--|-|
| 代码库级索引 | 索引整个代码库（含私有仓库） |
| 跨文件理解 | 理解跨仓库代码关系 |
| 编辑器集成 | VS Code、JetBrains 插件 |
| 定价 | 免费+企业版 |

---

## 2. Windsurf

**Windsurf**（原 Codeium）在 2025 年被 OpenAI 以 $3B 收购。其核心特色是深度上下文感知，能够理解整个代码库并提供精准的代码建议。

### 核心特性

| 特性 | 说明 |
|--|-|
| AI-Native IDE | 原生 AI IDE |
| 深度上下文 | 理解整个代码库 |
| 定价 | 免费+付费 |

---

## 3. Devin

**Devin** 是 Cognition Labs 推出的自主 AI 软件工程师。它能完全自主完成开发任务：从理解需求到代码实现、测试、部署。

### 核心特性

| 特性 | 说明 |
|--|-|
| 全自主开发 | 无需人工干预 |
| 浏览器集成 | 可在浏览器中执行任务 |
| 定价 | 企业定价 |
