## 1. Cursor 概述

**Cursor** 是 AI-First 的 VS Code fork，由 Svix 团队开发。Cursor raised $900M at a $9B valuation in August 2024.

核心特色：
- **Composer 模式**：跨文件编辑，Agent 模式开发
- **深度代码库索引**：理解整个项目结构
- **多模型支持**：Claude、GPT-4o 等
- **AI 原生编辑器**：对话、代码补全、生成一体化

---

## 2. Cursor 核心功能

### 2.1 Composer

Composer 是 Cursor 的核心功能，允许 AI Agent 跨多个文件生成和编辑代码。

### 2.2 代码库级理解

Cursor 索引整个代码库，AI 可以基于完整的上下文回答问题、生成代码。

### 2.3 多模型

支持 Claude、GPT-4o 等多种模型，用户可按需切换。
