## 1. Copilot 概述

**GitHub Copilot** 由 GitHub + OpenAI 合作开发，是 AI 编程助手的开创者。已升级至 GPT-5.2-Codex（2026年1月正式可用），成为目前最强大的 AI 编程助手之一。[来源: AI Tools](https://www.ai-all.info/tool/1712)

核心特色：
- **代码补全**：基于上下文的实时代码补全
- **Chat**：对话式编程助手
- **Agentic Memory**：公开预览，让 Copilot 学习项目特定细节
- **内置 Agent**：Explore、Task、Plan、Code-review

## 3. Copilot 最新特性

- **GPT-5.2-Codex**：2026年1月可用，最强编码模型
- **Agentic Memory**：跨工具共享项目特定记忆
