# 模块二 · 核心模块 导读

本模块是 ROS 2 知识库的**主干**，覆盖机器人开发者日常 90% 的通信与工程操作：从最基础的节点与发布订阅，到服务/动作、参数、坐标变换、QoS、CLI 与 launch、录制回放与调试工具。读完本模块，应能独立完成"搭通信架构 → 写节点 → 调参数 → 对齐坐标 → 调 QoS → 编排部署 → 录制调试"的完整闭环。

## 建议学习顺序

**01 → 05 → 06 → 02 → 03 → 04 → 07**

1. **[01 节点与发布订阅](01_节点与发布订阅.md)**：一切通信的基石，先吃透 executor 与数据通路。
2. **[05 QoS 与通信机制](05_QoS与通信机制.md)**：紧跟 01，理解"消息丢不丢、后到者拿不拿得到"——它是后续所有通信调试的钥匙。
3. **[06 CLI 与 Launch](06_ROS2_CLI与Launch系统.md)**：有了通信基础，学会用命令探查、用 launch 编排部署。
4. **[02 服务与动作](02_服务与动作.md)**：补齐请求-响应与长任务两种语义。
5. **[03 参数系统](03_参数系统与配置管理.md)**：让系统"可配置、可调优"。
6. **[04 TF2 坐标变换](04_TF2坐标变换.md)**：把多传感器数据对齐到同一坐标系。
7. **[07 录制与调试工具](07_ROSBag2与Rqt调试工具.md)**：用录制回放 + 可视化工具定位问题，收尾闭环。

> 说明：04 与 07 顺序可互换；若你正在做导航/建图，可提前读 04。
