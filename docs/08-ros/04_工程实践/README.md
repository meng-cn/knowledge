## 模块要点速览

1. **架构设计**（01）：进程边界 = 故障域 + 资源域；消息是模块间唯一契约；进程隔离 + lifecycle + supervisor 三层容错。
2. **测试**（02）：单元测纯库、集成测契约（含 QoS）、仿真回归放 CI 夜间。
3. **监控定位**（03）：先拓扑→再契约→后数据流；话题无数据先查 QoS；executor 阻塞是"节点卡死"头号原因。
4. **发布部署**（04）：colcon→lint/pre-commit→action-ros-ci→bloom→build.ros2.org→index.ros.org→apt/Docker；量产锁 distro。
5. **三栈协同**（05）：Nav2 出 `cmd_vel`、MoveIt 2 出关节轨迹、ros2_control 统一翻译成硬件指令；仿真换真机只换 hardware_plugin。
6. **仿真硬件**（06）：GZ Sim（开源通用）/Isaac Sim（视觉高保真）/Webots（教学）；x86/Jetson/MCU 三层各司其职。
