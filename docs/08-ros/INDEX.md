## 🎓 学习路径建议

### 初级（0-2 年 / 入门阶段）
1. **ch00-overview** ⭐⭐⭐ — 先建立全景：演进、分层、四大支柱
2. **01_基础概念** 全模块 ⭐⭐⭐ — 安装/工作空间/rosdep/消息与类型/生态
3. **02_核心模块** 前 4 篇 ⭐⭐ — 发布订阅/服务动作/参数/TF2
4. 动手：talker/listener → 自定义 srv → launch 多节点

### 中级（2-5 年 / 进阶阶段）
1. **02_核心模块** QoS/CLI/bag ⭐⭐ — 把"通信质量"与"运维工具"吃透
2. **03_高级话题** 架构/线程/实时 ⭐ — rcl/waitset/executor/RT 纪律
3. **04_工程实践** 架构/测试/诊断 ⭐ — 从"能跑"到"能维护"
4. 动手：组件化节点、intra-process、pre-commit CI、Nav2 跑通

### 高级（5 年+ / 专家阶段）
1. **03_高级话题** SROS2 / RMW 对比 / 组件化 — 安全域与跨 DDS 选型
2. **04_工程实践** 导航/规划/控制栈全链路 — 从 driver 到 planner
3. **05_前沿趋势** micro-ROS / LLM 融合 / 安全标准 — 保持技术敏感度
4. 源码贡献与深文 — 参与 ros2 组织 PR，写 TSC 报告级分析

## 📝 模块关系说明

### 为什么这样划分？

1. **全景优先**：ch00 放在最前，避免"只见局部不见体系"（ROS 2 的分层/四支柱是理解一切的锚点）。
2. **主干先行**：核心模块 = 90% 日常 API 面，覆盖 pub/sub/service/action/参数/TF/QoS/CLI/bag，是入门到中级的主线。
3. **底层下沉**：高级话题把 rcl/rmw/DDSSec/executor/RT 这些"面试高频 + 生产必踩"的深坑集中，避免散落在主干里稀释可读性。
4. **工程收敛**：工程实践把"怎么建、怎么测、怎么部署、怎么跑通机器人"的闭环集中，与源码分层互补。
5. **前沿外延**：前沿趋势聚焦 micro-ROS / LLM+VLA / 安全标准 / 跨平台 / 产业 5 条外延线，明确标注哪些是事实、哪些是推断。
