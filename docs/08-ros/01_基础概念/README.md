> ROS 2 知识库《模块一：基础概念》导读。本模块回答"ROS 2 是什么、和 ROS 1 差在哪、怎么装、怎么构建、消息类型长什么样、生态由谁组成"这六个入门必答题。

## 建议学习顺序

1. **01 → 06**：先建立"ROS 2 是什么"与"生态长什么样"的全局观（06 难度最低，可与 01 对读）。
2. **02**：带着 ROS 1 或"为什么重写"的疑问，理解两大版本的架构差异。
3. **03 → 04**：动手装环境、建工作区、编译第一个包——这是所有后续实践的地基。
4. **05**：深入消息/服务/动作类型系统，为自定义接口做准备。

> 每篇末尾都有「核心面试三问」，覆盖边界条件/极端场景/失败模式，可直接用于自测与复习。
